# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ocprobe, please report it
by opening a GitHub issue at:
https://github.com/SunnyJayaRaju/oc-model-manager/issues

For sensitive reports you'd prefer not to disclose publicly before a
fix is available, contact the maintainer directly via their GitHub
profile: https://github.com/SunnyJayaRaju

There is no bug bounty program at this time. We'll acknowledge reports
and work on a fix as soon as possible; response times are best-effort
for this project.

## Supported Versions

Only the latest released version (currently tracked via the VERSION
file and GitHub Releases) receives fixes. There is no formal LTS policy.
