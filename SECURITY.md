# Security Policy

## Reporting a Vulnerability

**For sensitive vulnerabilities:** Use GitHub Security Advisories (preferred) or contact the maintainer privately via their GitHub profile:
- GitHub Security Advisories: https://github.com/SunnyJayaRaju/oc-model-manager/security/advisories/new
- Maintainer profile: https://github.com/SunnyJayaRaju

This allows coordinated disclosure before a fix is publicly available.

**For non-sensitive reports:** Open a GitHub issue at:
https://github.com/SunnyJayaRaju/oc-model-manager/issues

There is no bug bounty program at this time. We'll acknowledge reports and work on a fix as soon as possible; response times are best-effort for this project.

## Supported Versions

Only the latest released version (currently tracked via the VERSION file and GitHub Releases) receives fixes. There is no formal LTS policy.
